# 게시글 CRUD 서비스 - 나쁜 프롬프트 실험 세트

## 목적
같은 프로젝트를 **최소한의 지시만으로** 구현했을 때 어떤 결과가 나오는지 비교하기 위한 실험용 프롬프트 세트다.

---

## 공통 실험 조건

- 빈 저장소가 아니라 **같은 초기 상태의 Spring Boot 프로젝트**에서 시작한다.

### 권장 초기 프로젝트 상태

- Java 21
- Spring Boot 3.x
- Gradle
- package: `com.example.board`

### 기본 의존성

- Spring Web
- Spring Data JPA
- Spring Security
- Validation
- H2 Database
- Lombok
- Spring Boot Test

### 데이터베이스

- 실험 환경 단순화를 위해 **H2 In-Memory Database** 사용

### 프론트엔드

간단한 UI 검증을 위해

- HTML
- CSS
- Vanilla JavaScript

사용

UI 범위

- 로그인 페이지
- 게시글 목록
- 게시글 작성
- 게시글 수정

---

## 실험 규칙

네 가지 실험 방식은 **모두 동일한 초기 프로젝트 상태에서 시작한다**

실험 방식

1. 나쁜 프롬프트
2. 구조화 프롬프트
3. PRD 기반 프롬프트
4. PRD + Bottom-up + TDD 프롬프트

---
