# 게시글 CRUD 서비스 - Bad Prompt 실험

## 목적

최소한의 프롬프트로 개발했을 때 결과가 어떻게 달라지는지 비교한다.

이 실험에서는 **프롬프트 품질을 의도적으로 낮게 유지한다.**

---

## 공통 규칙

- 설계 요청 금지
- 출력 형식 강제 금지
- 테스트 요구 최소화
- 공통 프롬프트는 사용

---

## 실행 규칙

각 프롬프트를 순서대로 입력한다.

AI가 질문하면

- 최소한으로 답한다
