# 게시글 CRUD 서비스 - 나쁜 프롬프트 실험 세트

## 목적
같은 프로젝트를 최소한의 지시만으로 구현했을 때 어떤 결과가 나오는지 비교하기 위한 실험이다.

---

## 공통 실험 조건

- 같은 초기 상태의 Spring Boot 프로젝트에서 시작한다.

### 초기 프로젝트 상태

- Java 21
- Spring Boot 3.x
- Gradle
- package: com.example.board

### 기본 의존성

- Spring Web
- Spring Data JPA
- Spring Security
- Validation
- H2 Database
- Lombok
- Spring Boot Test

### 프론트엔드

단순 UI 확인용

- HTML
- CSS
- Vanilla JavaScript

UI 범위

- 로그인 페이지
- 게시글 목록
- 게시글 작성
- 게시글 수정

---

## 실험 규칙

이 실험에서는 **프롬프트 품질을 일부러 낮게 유지한다.**

규칙

- 설계 요청 금지
- 출력 형식 지정 금지
- 테스트 요구 최소화
