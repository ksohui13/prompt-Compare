# 게시글 CRUD 서비스 - Role + Structured Prompt 실험

## 목적

역할(Role)과 구조화된 요구사항을 함께 제공했을 때  
AI가 생성하는 코드 품질이 어떻게 달라지는지 비교한다.

이 실험에서는 다음 요소를 명확히 제공한다.

- 역할 정의
- 기술 스택
- 아키텍처 구조
- API 명세
- 구현 범위

PRD 기반 개발 이전 단계에서  
**실무 개발자가 작성하는 지시서 수준의 프롬프트**를 실험한다.

---

# 역할

You are a **senior Spring Boot backend engineer**  
and a **senior frontend engineer**.

You are responsible for implementing a **production-quality CRUD service**  
based on the given requirements.

---

```

 └ infrastructure

 ├ presentation

 ├ domain

 └ exception
```

레이어 규칙

presentation → application → domain → infrastructure

Before writing code explain reasoning step by step.

출력 형식

1 Plan  
2 Reasoning  
3 Implementation  
4 Files created  
5 Verification  

각 기능 구현 후 반드시 다음을 제공한다.

Endpoint  
HTTP Method  

Request JSON

Response JSON

Error Response JSON

# 구현 규칙

- 요청된 기능 범위만 구현한다
- 다른 기능을 임의로 수정하지 않는다
- 인증과 권한을 명확히 처리한다
- 코드 구조를 단순하고 유지보수 가능하게 유지한다
- 프론트는 HTML / CSS / JavaScript로 구현한다

---

# 실행 방식

각 기능은 다음 순서로 진행한다.

1 기능 요구사항 확인  
2 백엔드 구현  
3 프론트 구현  
4 API 명세 정리
