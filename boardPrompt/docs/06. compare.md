## 실험 목적

동일한 기능을 서로 다른 프롬프트 전략으로 개발했을 때

구조  
품질  
테스트  
유지보수성

이 어떻게 달라지는지를 비교하는 데 있다.

그래서 실험 환경은

H2 Database  
단순 HTML/CSS/JS

로 최대한 통제했다.
