# 게시글 CRUD 서비스 - 나쁜 프롬프트 실험 세트

## 목적
같은 프로젝트를 **최소한의 지시만으로** 구현했을 때 어떤 결과가 나오는지 비교하기 위한 실험용 프롬프트 세트다.

## 공통 실험 조건

- 빈 저장소가 아니라 **같은 초기 상태의 Spring Boot 프로젝트**에서 시작한다.

### 권장 초기 프로젝트 상태

- Java 21
- Spring Boot 3.x
- Gradle
- package: `com.example.board`

### 기본 의존성

- Spring Web
- Spring Data JPA
- Spring Security
- Validation
- H2 Database
- Lombok
- Spring Boot Test

### 데이터베이스

- 실험 환경 단순화를 위해 **H2 In-Memory Database** 사용
- 목적: DB 환경 차이로 인한 변수 제거
- 운영 DB(MySQL/PostgreSQL) 환경은 본 실험 범위에 포함하지 않는다

### 프론트엔드

- 간단한 UI 검증을 위해 **HTML + CSS + Vanilla JavaScript** 사용
- 목적: 프론트엔드 프레임워크로 인한 복잡도 증가 방지
- UI 범위
  - 로그인 페이지
  - 게시글 목록
  - 게시글 작성
  - 게시글 수정

### 실험 규칙

- 네 가지 실험 방식은 **모두 동일한 초기 프로젝트 상태에서 시작한다**

실험 방식

1. 나쁜 프롬프트
2. 구조화 프롬프트
3. PRD 기반 프롬프트
4. PRD + Bottom-up + TDD 프롬프트

### 실험 진행 방식

- 각 단계 프롬프트 실행 후
  - 코드 반영
  - 빌드 또는 실행 확인
  - 정상 동작 확인 후 다음 단계 진행

### 실험 기록

다음 자료를 반드시 기록한다.

- 프롬프트 로그
- 생성된 코드 구조
- 테스트 코드 수
- 실행 결과
- 주요 문제 발생 지점

이 기록은 발표 시 **프롬프트 방식에 따른 개발 결과 비교** 자료로 활용한다.

## 사용 규칙
1. 아래 프롬프트를 **한 번에 하나씩 그대로** 입력한다.
2. 프롬프트 밖 설명을 추가하지 않는다.
3. AI가 질문하면 자세히 설명하지 말고, 가능하면 짧게 답하거나 그대로 진행하게 둔다.
4. 단계별 결과를 캡처해 두면 발표 비교에 매우 좋다.
