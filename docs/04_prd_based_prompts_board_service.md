# 게시글 CRUD 서비스 - PRD 기반 프롬프트 세트

## 사용 전 준비
1. 프로젝트 루트에 `PRD.md` 파일을 두고, 내용은 제공된 `03_board_service_prd.md` 를 그대로 사용한다.
2. 같은 초기 상태의 Spring Boot 프로젝트에서 시작한다.
3. 아래 프롬프트를 **위에서부터 하나씩** 입력한다.
4. 각 단계가 끝나면 빌드 또는 실행 확인 후 다음 단계로 간다.

## 공통 작업 원칙
- 항상 프로젝트 루트의 `PRD.md`를 기준으로 판단한다.
- PRD에 없는 임의 기능은 추가하지 않는다.
- 필요한 파일만 생성/수정한다.
- 불필요한 대규모 리팩터링은 하지 않는다.
- 한 단계가 끝날 때마다 생성/수정 파일 목록을 보여주게 한다.

## 1. PRD 분석과 구현 계획

```text

작업 목표

출력 요구
1. 구현 범위를 7줄 이내로 요약
2. 패키지 구조 제안

4. 구현 순서를 단계별로 제안
5. 위험 요소와 애매한 점 정리

중요
- 코드 생성 금지
- PRD 범위를 벗어난 기능 제안 금지
```

```text
2. 코드 변경
3. 생성/수정 파일 목록
4. 다음 단계 전에 확인할 포인트
```

```text
2. 코드 변경
```

```text
2. 추가한 테스트 코드
3. 생성/수정 파일 목록
4. 남은 기술 부채와 개선 포인트
```
