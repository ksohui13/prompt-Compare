# 게시글 CRUD 서비스 - PRD + Bottom-Up + TDD 프롬프트 세트

## 사용 전 준비
1. 프로젝트 루트에 `PRD.md` 파일을 두고, 내용은 제공된 `03_board_service_prd.md` 를 그대로 사용한다.
2. 같은 초기 상태의 Spring Boot 프로젝트에서 시작한다.
3. 아래 프롬프트를 **위에서부터 하나씩** 입력한다.
4. 한 단계가 끝나면 테스트를 실행해 통과 여부를 확인하고 다음 단계로 간다.

## 공통 작업 원칙
- 항상 프로젝트 루트의 `PRD.md`를 기준으로 판단한다.
- 모든 단계에서 **Red → Green → Refactor** 순서를 지킨다.
- 이번 단계 범위를 벗어난 기능은 구현하지 않는다.
- 먼저 실패하는 테스트를 작성한 뒤, 테스트를 통과시키는 최소 코드만 구현한다.
- 마지막에 중복 제거, 네이밍 정리, 구조 정리를 최소 범위에서 수행한다.
- 각 단계 끝에 **실행한 테스트 목록과 결과**를 보여주게 한다.

2. Green 단계 구현 내용
3. Refactor 내용

5. 실행한 테스트와 결과
